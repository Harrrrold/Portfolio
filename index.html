What is SmartQuest?

SmartQuest is a gamified learning management system (LMS) designed specifically for Grade 4 pupils in Cebu City. It is a supplementary educational platform that combines mathematics education with interactive gameplay elements.

Problem Statement

  • Low Math Proficiency: Students struggle with mathematical concepts and need additional support
  • Parental Challenges: Parents often lack the time, confidence, or familiarity with modern teaching strategies ("new math") to effectively help their children with homework

Project Goal

The overarching goal is to design and develop a gamified learning platform that serves as a supplementary practice tool to improve mathematical proficiency and motivation among Grade 4 pupils.

BookTrack

A Simple Web App For Searching, Reserving, And Managing Library Books

Web Application

Project Overview

BookTrack is a PHP-based web application that allows library members to register an account, search for books, reserve available titles, and bookmark or mark favorite books for easy access later. Administrators can manage the book catalog and member accounts through an easy-to-use interface. This system aims to simplify book borrowing processes, ensure accurate tracking of book availability, and provide a user-friendly environment for both members and librarians.

Key Features

  • User Management: User registration and login system for library members
  • Book Search: Search and filtering by title, availability, or category
  • Borrowing System: Complete borrowing, reserving, and return process tracking
  • Admin Dashboards: Separate dashboards for System Admin, Library Admin, and Library Moderator
  • Library Management: Creation, update, and moderator assignment for libraries
  • User Features: View due dates, borrowing history, and bookmark favorite books
  • Notifications: Alerts for borrowers about upcoming and overdue books
  • Activity Logging: Book status logging for admins and moderators

Project Scope

In Scope:
  • User registration and login system
  • Book search and filtering by title, availability, or category
  • Borrowing, reserving, and return process tracking
  • Dashboards for System Admin, Library Admin, and Library Moderator
  • Library management (creation, update, and moderator assignment)
  • View due dates and borrowing history for members
  • Bookmarking or liking books for quick access
  • Notifications for borrowers about upcoming and overdue books
  • Book status logging for admins and moderators
Out of Scope:
  • Digital reading of books (no full-text access)
  • Online payment processing
  • Inter-library loan functions

FridgeWatch

An Application That Detects If A Refrigerator Door Has Been Left Open For Too Long. Alerts And Status Are Stored In The Cloud And Viewable Through A Mobile App.

IoT Project

Project Overview

FridgeWatch is an Internet of Things (IoT) solution designed to monitor the status of a refrigerator door. A common issue in households and businesses is leaving refrigerator doors unintentionally open, which leads to food spoilage, increased electricity consumption, and reduced appliance lifespan. FridgeWatch addresses this problem by using a magnetic reed switch sensor connected to an ESP32 microcontroller to detect whether the refrigerator door is open or closed.

When the door remains open for longer than a predefined threshold, the system triggers an alert. This status is transmitted via Wi-Fi to a cloud platform (Firebase), where the data is stored and made accessible through a dedicated mobile application. The application provides real-time monitoring, status updates, and alerts, ensuring users are notified promptly and can take corrective action.

Key Features

  • Real-time Monitoring: Continuous monitoring of refrigerator door status
  • Smart Alerts: Automatic notifications when door is left open beyond threshold
  • Cloud Storage: All status updates and activity logs stored in Firebase
  • Mobile App: Android application for viewing status and receiving notifications
  • Activity Logs: Historical tracking of door open/close events
  • Wi-Fi Connectivity: Seamless connection to local Wi-Fi network

Hardware Components

Microcontroller: ESP32 (Dual-core, 2.4GHz Wi-Fi) - Data processing & Wi-Fi connection
Magnetic Reed Switch: GPS-30 - Detects presence or absence of magnetic field (Normally open/closed contacts, 10-30V operating range)
Power Supply: USB 2.0 Cable (5V/3A) - Provides stable power and programming interface
Prototyping: Breadboard (MB-102, 830 tie-points) and Jumper Wires (22 AWG) - For circuit prototyping

Connectivity Specifications

  • Protocol: Wi-Fi 802.11 b/g/n (ESP32 connects to local Wi-Fi network)
  • Cloud Service: Firebase Realtime Database
  • Mobile Access: Android application connected to Firebase SDK for data sync and notifications
